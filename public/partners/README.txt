Logos des partenaires affichés sur la page /partenaire.

Dépose ici un fichier PNG (fond transparent de préférence) par partenaire,
nommé exactement d'après le "slug" défini dans src/pages/PartnerSpace.tsx :

  bpifrance.png
  caisse-epargne.png
  bnp-paribas.png
  credit-agricole.png
  initiative-france.png
  cci-france.png

Tant qu'un logo est absent, le nom du partenaire s'affiche en typographie
stylisée (fallback automatique). Hauteur d'affichage : ~56 px.
